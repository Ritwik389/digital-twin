Source graph

Built from the included corpus before anyone chats. Public topic nodes have dated excerpts and bounded, source-supported graph traversal.

Conversation memory

Neo4j facts update every five completed turns. Inspect, edit, or forget individual facts, and see which facts were included in an answer.

Content versions

Transcript hashes detect edits. Re-ingestion replaces obsolete chunks; a new source-map fingerprint retires stale graph entries while preserving a previous snapshot.

Original assets and source files remain part of the Space. Evaluation results include the corpus version and run date. Visitor identity and server chat-history storage retain the project’s existing design.
